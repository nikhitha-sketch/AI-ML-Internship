Student Score Prediction
Project Overview
This project uses Linear Regression to predict student scores based on study hours.
Dataset
- student_scores.csv
- Features:
  - Study Hours
  - Score
Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
Project Steps
1. Import libraries
2. Load dataset
3. Visualize data
4. Train the Linear Regression model
5. Predict scores
6. Evaluate the model using:
   - MAE
   - MSE
   - R² Score
7. Build a simple prediction application
Results
The model predicts student scores based on study hours with good accuracy.
Overall Summary
This project demonstrates the complete machine learning workflow, including data loading, visualization, model training, prediction, evaluation, and deployment through a simple prediction program. It provides a basic understanding of Linear Regression using Python and Scikit-learn.
